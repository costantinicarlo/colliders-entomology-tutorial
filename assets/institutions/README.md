# Institutional footer logos

Official assets displayed on the [MIVEGEC website](https://mivegec.fr/fr), downloaded 2026-09-25 and retained without image modifications:

- `mivegec.png`: https://mivegec.fr/wp-content/uploads/2020/09/logo.png
- `ird.png`: https://mivegec.fr/wp-content/uploads/2024/11/logoIRD_Horizontal_Baseline_FR_Blanc-300x212.png
- `cnrs.png`: https://mivegec.fr/wp-content/uploads/2020/09/logo_CNRS@2x.png
- `universite-montpellier.png`: https://mivegec.fr/wp-content/uploads/2021/04/logo_um_original_blanc-1.png

Both title slides use the local `fieldnote-title-footer` template and explicit `title-footer` class, with the same green background as the title’s left border. Each logo links to its institution. The footer occupies a fixed 32% × 7% slide grid. Visible logos are limited to 32px high and 90px wide, smaller than the CC BY badge. Link containers and the footer clip overflow; IRD and Montpellier transparent margins are compensated inside those containers. The original asset files are unchanged. Institutional marks remain subject to their respective owners' rights; the project's CC BY license does not relicense these logos.
