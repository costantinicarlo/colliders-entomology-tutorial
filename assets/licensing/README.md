# Creative Commons badge

`cc-by.svg` is the official Creative Commons Attribution badge, downloaded from https://mirrors.creativecommons.org/presskit/buttons/88x31/svg/by.svg.

The title slides embed it locally at 118 pixels using the Fieldnote Academic `corner-logo` class and link to the CC BY 4.0 license deed. The linked badge specifies the license through its CC BY 4.0 deed URL; the opposite footer contains institutional logos. No remote image is needed when presenting.
